# MAN & VAN Website

This repository contains a website created for a small startup company offering moving and transport services in Wrocław and the surrounding area.

## Project status

Development is currently **paused**. The startup encountered import-related difficulties and budget constraints, so the company decided not to continue with the website for the time being.

The project is therefore a work in progress and is not currently hosted as a production website.

## What is already included

- Responsive layout for desktop and mobile devices
- Information about the company's moving and transport services
- Vehicle photo gallery
- Service-area map
- Polish, English, Russian, and Ukrainian language options
- Light and dark themes
- Contact links and call-to-action sections

## Work still required

Before the website can be launched, it needs several final adjustments and materials from the client/company, including:

- Final, high-quality photos of the transport vehicle and services
- Review and approval of the company information, service details, and contact details
- Replacement of any temporary or placeholder content
- Final testing of the layout, translations, links, and contact actions
- Hosting, domain configuration, and deployment
- Final production checks for performance, accessibility, and browser compatibility

## Technology

The website is a static front-end project built with HTML, CSS, and JavaScript. It also uses Leaflet for the map and Lottie animations for selected icons.

## Running locally

No build step or package installation is required. You can open `index.html` directly in a browser or serve the folder with a simple local web server, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
